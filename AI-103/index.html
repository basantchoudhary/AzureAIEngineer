GlossaryOld names, new names, and terms

Renames you'll meet in old material

Azure AI Studio → Azure AI Foundry → Microsoft Foundry
The platform. The old portal is now "Foundry (classic)".
Azure AI services / Cognitive Services → Foundry Tools
e.g. "Azure Speech in Foundry Tools". The resource is now a Foundry resource.
Hub-based project → Foundry project
Hub projects are classic; new work uses Foundry projects.
Threads / runs / assistants → conversations / responses / agent versions
Agents v2, on the Responses API.
Azure AI User → Foundry User
Same role ID. Azure AI Developer belongs to Azure ML hubs.
Content filters → guardrails
A named set of controls: risk, intervention point, action.
Knowledge agents → knowledge bases
Azure AI Search agentic retrieval; Foundry IQ for agents.
Connected Agents → A2A tool
Connected Agents isn't in the new Agent Service.
Prompt flow, Foundry Workflows → Agent Framework
Prompt flow retires 20 Apr 2027; Workflows 1 Dec 2026.
Monthly api-version → v1 routes
/openai/v1/ with the standard OpenAI client.
DALL-E 3 → gpt-image-2 / 2.5
DALL-E 3 retired March 2026.
LUIS → (retired) · CLU, sentiment, summarisation → legacy
Use LLMs with structured outputs for new text analysis.
RRF
Reciprocal Rank Fusion: how hybrid search merges keyword and vector results.
PTU
Provisioned throughput units: reserved capacity for predictable latency.
ASR
Attack Success Rate, the AI Red Teaming Agent's metric.
C2PA / Content Credentials
Signed provenance metadata on generated images.
